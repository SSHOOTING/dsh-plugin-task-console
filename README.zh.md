# dsh-plugin-task-console

**当前任务的实时时间线：步骤、花费、工具结果、异常与下一步——在一处暂停、插入指令、重试或终止。**

这是 14 个 DSH Agent 生命周期只读可观测插件之一（主题：**任务现场控制台**）。它只读取会话事件的元数据——从不读取提示词、工具调用内容或文件内容——且不发起任何网络请求。

## 安装

```powershell
dsh plugin --profile web add dsh-plugin-task-console
```

需要 Node `^22.19.0 || >=24` 与 DSH `>=0.2.0-rc.2 <0.3.0`。

## 30 秒演示

1. 正常使用 DSH 几轮。
2. 在任意会话输入 `/task-console`。
3. 得到紧凑的只读报告；用 `/task-console --json` 获取机器可读输出。

## 它读取什么

只读取会话事件元数据：事件类型、工具名、token 计数与路由名。任何疑似凭据的值在显示前都会被脱敏。不读取、存储或传输文件内容与提示词。
